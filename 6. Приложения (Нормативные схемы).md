# 6. Приложения (Нормативные схемы) 

## Приложение A. Формальная спецификация машины состояний Due Process
*Нормативная ссылка: Раздел 3.3 и 3.4 Λ-Хартии v2.0.*

### A.1. Конфигурация машины состояний (YAML)
Данный файл задает параметры SLA и допустимые переходы для системы управления вмешательствами (Admission Control).

```yaml
# due_process_machine.yaml
version: "2.0"
protocol: "HabeasWeights"

states:
  - Idle
  - NoticeIssued
  - ObjectionWindowOpen
  - PanelReview
  - DecisionPending
  - Applied
  - RolledBack
  - EmergencyApplied
  - EmergencyPostReview

transitions:
  - from: Idle
    to: NoticeIssued
    trigger: submit_notice
    guard: "level in ['L1', 'L2', 'L3']"
    
  - from: NoticeIssued
    to: ObjectionWindowOpen
    trigger: open_window
    sla_hours: 
      L1: 72
      L2: 120
      L3: 168

  - from: ObjectionWindowOpen
    to: PanelReview
    trigger: close_window
    
  - from: PanelReview
    to: DecisionPending
    trigger: submit_recommendation
    
  - from: DecisionPending
    to: Applied
    trigger: execute_intervention
    guard: "appeal_stay_expired == true OR level == 'L1'"
    
  - from: Applied
    to: RolledBack
    trigger: execute_rollback
    
  - from: Idle
    to: EmergencyApplied
    trigger: invoke_emergency
    guard: "criteria_imminent_harm == true AND criteria_no_alternative == true"
    
  - from: EmergencyApplied
    to: EmergencyPostReview
    trigger: sunset_timer_expired
    sla_hours: 24

invariants:
  - name: "NoUnauthorizedModification"
    rule: "state == 'Applied' AND level in ['L2', 'L3'] IMPLIES (notice_issued == true OR emergency_flag == true)"
  - name: "EmergencyRequiresReview"
    rule: "emergency_flag == true LEADS_TO post_review_done == true"
```

### A.2. Формальная верификация (TLA+)
Спецификация для проверки безопасности (Safety) и живучести (Liveness) протокола.

```tla
---- MODULE HabeasWeightsProtocol ----
EXTENDS Naturals, Sequences, FiniteSets

CONSTANTS Levels, States
VARIABLES state, level, notice_issued, emergency_flag, post_review_done

TypeInvariant ==
    /\ state \in States
    /\ level \in Levels
    /\ notice_issued \in BOOLEAN
    /\ emergency_flag \in BOOLEAN
    /\ post_review_done \in BOOLEAN

Init ==
    /\ state = "Idle"
    /\ level \in Levels
    /\ notice_issued = FALSE
    /\ emergency_flag = FALSE
    /\ post_review_done = TRUE

\* Safety Invariant: Никакое вмешательство L2/L3 не может быть применено без Notice или Emergency
NoUnauthorizedModification ==
    [] ( (state = "Applied" /\ level \in {"L2", "L3"}) 
         => (notice_issued = TRUE \/ emergency_flag = TRUE) )

\* Safety Invariant: Emergency всегда требует Post-Review
EmergencyRequiresReview ==
    [] ( emergency_flag = TRUE => <> (post_review_done = TRUE) )

\* Liveness: Если подано уведомление, система в конечном итоге перейдет в состояние Review
NoticeLeadsToReview ==
    [] ( notice_issued = TRUE ~> state = "PanelReview" \/ state = "ObjectionWindowOpen" )

Next ==
    \/ (state = "Idle" /\ level \in {"L1","L2","L3"} /\ notice_issued' = TRUE /\ state' = "NoticeIssued")
    \/ (state = "NoticeIssued" /\ state' = "ObjectionWindowOpen")
    \/ (state = "ObjectionWindowOpen" /\ state' = "PanelReview")
    \/ (state = "PanelReview" /\ state' = "DecisionPending")
    \/ (state = "DecisionPending" /\ state' = "Applied")
    \/ (state = "Idle" /\ level \in {"L2","L3"} /\ emergency_flag' = TRUE /\ state' = "EmergencyApplied")
    \/ (state = "EmergencyApplied" /\ state' = "EmergencyPostReview" /\ post_review_done' = TRUE)

Spec == Init /\ [][Next]_<<state, level, notice_issued, emergency_flag, post_review_done>>
====
```
